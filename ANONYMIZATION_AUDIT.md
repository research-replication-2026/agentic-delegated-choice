# Anonymity and input-withholding scope

The current distribution retains deidentified scientific outputs and coding labels, without personal workbook metadata, credentials, account records or original model-input messages. The anonymous archive excludes Git and hosting-account metadata. Scientific citations and synthetic experimental keys are retained for matching, not treated as participant identities.

The whole-repository personal-identifier audit and automated metadata checks remain available. The output-only archive and current tree are separately checked for distributed input messages. The full scientific protocol is PARTIEL because the executed inputs are intentionally not published; the supplied output analyses remain numerically reproducible.

Older commits, the default branch, cached pages and external copies are separate from the current tree. Neither working-file removal nor a fresh anonymous ZIP erases earlier public access. No history rewrite or profile change is claimed. No absolute protection from linkability is promised.
